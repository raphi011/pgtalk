# Names become numbers

The analyzer resolves every name against the catalog. After it runs, nothing in
the query is a string any more.

<Runnable
  appearAt={1}
  sql={`SELECT attname, atttypid::regtype AS type, attnum
FROM pg_attribute
WHERE attrelid = 'customers'::regclass AND attnum > 0
ORDER BY attnum;`}
/>
