export const notes = `A plan is not a program that runs top to bottom. It is a tree of
iterators, and the top node pulls.
Walk one row through: Aggregate asks Filter for a row, Filter asks Seq Scan,
Seq Scan returns one tuple. Repeat 500000 times.
This is why LIMIT can be nearly free — the top node simply stops pulling — and
why a sort in the middle of a tree is not, because a sort cannot answer until
it has seen everything.
"Actual loops" in a plan is this picture: how many times a subtree was asked to
start over.`;
